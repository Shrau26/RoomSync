REQUIRES: Firebase configured in src/firebase/config.js

── Single laptop test first ────────────────────────────────
  1. Open http://localhost:3000 in Chrome (normal window)
  2. Open http://localhost:3000 in Chrome (Incognito window → Ctrl+Shift+N)
  3. Login as User A in normal window
  4. Login as User B in incognito window
  5. In User A window → Browse Rooms → click "Contact" on any room
  6. Chat page opens for User A with owner contact
  7. Type "Hello!" and press Enter

  CHECK: Does "Hello!" appear instantly in User B's incognito window
         (without User B refreshing the page)?

✅ PASS: Message appears on both sides within 1-2 seconds → Firebase real-time working!
❌ FAIL message only shows on sender side → Firebase config wrong or Firestore rules missing

── Two laptop test ─────────────────────────────────────────
  1. On Laptop 1 — make sure app is running: npm run dev
  2. On Laptop 2 — open browser → go to: http://YOUR_LAPTOP1_IP:3000
     (find your IP: open cmd → type ipconfig → look for IPv4 Address e.g. 192.168.1.5)
     So Laptop 2 opens: http://192.168.1.5:3000
  3. Both laptops must be on SAME WiFi network
  4. Login as different users on each laptop
  5. Start a chat between them

  If "http://192.168.1.5:3000" doesn't open on Laptop 2:
  Stop the app on Laptop 1, then run:
    npm run dev -- --host
  Now Laptop 2 can access it.

✅ PASS: Message typed on Laptop 1 appears on Laptop 2 within 1 second
❌ FAIL can't connect → both must be on same WiFi

Open browser → press F12 → click Console tab

After loading the app, check for these messages:
  ✅ No red errors = everything loaded fine
  🟡 Yellow warnings = minor issues, app still works
  🔴 Red errors = something needs fixing

Common red errors and fixes:
  "Firebase: Error (auth/invalid-api-key)"
    → Firebase config wrong in src/firebase/config.js

  "Missing or insufficient permissions"
    → Firestore rules not set. Go to Firebase Console → Rules → paste correct rules

  "Cannot read properties of undefined (reading 'uid')"
    → Not logged in. Login first before testing features

  "Failed to fetch" on Roommate Match
    → Flask not running. Run: python flask-api/app.py

  "net::ERR_CONNECTION_REFUSED localhost:5001"
    → Flask not running
